# Rodinná kasa

Statická webová aplikace pro Vercel. Přihlášení a data běží na Firebase (Authentication, Firestore).

1. Do `firebase-config.js` vlož konfiguraci webové aplikace z Firebase.
2. Obsah `firestore.rules` vlož ve Firebase do Firestore > Rules a publikuj.
3. Doménu z Vercelu přidej v Firebase do Authentication > Settings > Authorized domains.
